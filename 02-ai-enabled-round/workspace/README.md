# Workspace

An empty Maven project to practice in, with JUnit 5 ready.
Open this folder in an editor with an AI agent (Copilot Chat, Cursor).

```bash
mvn -q test
```

Put your classes in `src/main/java/com/practice/ai/` and tests in
`src/test/java/com/practice/ai/`. Delete `SmokeTest.java` once you have
your own tests.
