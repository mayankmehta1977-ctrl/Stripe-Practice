# Stripe SWE intern interview prep

Practice material for Stripe's software engineering intern interviews.

| Folder | What it is |
|---|---|
| `java-integration-exercise/` | 60-minute Integration-round mock in Java: existing codebase, spec, API docs, mock server, reference solution, and an interviewer's guide |
| `python-integration-exercise/` | The same exercise in Python |
| `practice-problems/stripe_practice.py` | Worked, tested solutions to 10 problems candidates reported from Stripe interviews, each in multiple parts |
| `practice-problems/tree_and_word_break.py` | Tree serialize/deserialize and Word Break, with variants |

Start with `java-integration-exercise/README.md`. Don't open the `solution/`
folders until the timer runs out.

The exercises are modeled on the format Stripe describes in its candidate
prep guide. They are not Stripe's actual interview questions.
