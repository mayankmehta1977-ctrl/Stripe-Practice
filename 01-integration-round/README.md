# Round 1: Integration exercise

Stripe's format: 60 minutes with a Stripe engineer. You add a feature to an
existing codebase using a spec, API documentation and common libraries.
Looking things up is allowed. Graded on: ability to help yourself,
abstractions and code, correctness/testing/debugging, and interaction.

Everything is in `java/`:

- `java/README.md`: setup and how to run the 60-minute practice
- `java/SPEC.md` and `java/API.md`: the task and the API docs
- `java/starter/`: the existing codebase to work in
- `java/mock_api/`: local mock server (`java mock_api/MockLedgerServer.java`)
- `java/INTERVIEWER_GUIDE.md`: questions, hints and scoring for whoever runs the mock
- `java/solution/`: reference solution. Open only after practicing.
